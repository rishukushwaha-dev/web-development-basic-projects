## 🚀 How to Run These Projects Locally:-

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the project folder:**
   ```bash
   cd HTML-CODES
   ```
3. **Open any HTML file:**
   - Simply double-click any `.html` file (or right-click and open with your browser) to run it instantly!
   - _Tip:_ Use the **Live Server** extension in VS Code for the best experience.
